#  Stop Watch App (Android)

A modern and beautifully designed Stopwatch application built using Kotlin in Android Studio.  
This app allows users to measure time with millisecond precision using Start, Pause, and Reset functionality.

---

##  Features

- ⏳ Displays Minutes, Seconds, and Milliseconds
- ▶️ Start Timer
- ⏸ Pause Timer
- 🔄 Reset Timer
- 🎨 Modern UI with Gradient Background
- 🔘 Rounded Colorful Buttons
- 📲 Responsive Layout using ConstraintLayout

---

##  Tech Stack

- Kotlin
- Android Studio
- XML Layout Design
- Material Design UI
- ConstraintLayout
